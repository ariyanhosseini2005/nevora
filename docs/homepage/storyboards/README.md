# NEVORA production masters

The high-resolution storyboard masters, intermediate frame packs, proxies, and
review videos in this directory are kept locally and are intentionally excluded
from Git. Together they are roughly 1.9 GB and are not required to build or run
the website.

The production-ready web sequence is included in:

`frontend/public/images/journey/frames-v010`

That directory contains the complete F0204-F0743 WebP sequence and its manifest.
The local masters can be restored from the project workstation archive when a
new web sequence needs to be generated.
